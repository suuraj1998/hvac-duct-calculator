# HVAC Duct Sizing & Airflow Calculator (Flutter & Dart)

A production-ready, globally localized HVAC duct sizing mobile application built with Flutter & Material 3.

## Features
- **ASHRAE Fundamentals**: Huebscher's equivalent circular diameter equation.
- **European EN 1505 / EN 1506**: Metric standards and standard round duct increments (63mm to 1250mm).
- **Offline SQLite DB**: SMACNA Sheet Metal Gauges, DW144 standards, and velocity guidelines.
- **AdMob**: Bottom banner, 1-hour frequency-capped interstitial, and rewarded video ads.
- **RevenueCat**: $9.99 Lifetime Pro Unlock & $1.99/month subscriptions.
- **PDF Job Sheet**: Vector job sheet generator with printing support.

## Getting Started
```bash
flutter pub get
flutter run
```
